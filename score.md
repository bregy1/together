

### User scores
Jeder User hat einen  Verlässlichkeit Score. Der Score it am Anfang 
auf 0, bzw. Grau. Sobald ein Benutzer an einigen Aktiviäten teilgenommen hat (solo aktivitäten zählen nicht)
WIrd der Score gerechnet. 

Der score wird  postitiv oder negativ beeinflusst von:
 - Wie oft meldet sich der Uswer ab
 - Wie oft nimmt er User wirklich Teil
 - hat der User Reports erhalten welhe von Admins verifitziert wurden
